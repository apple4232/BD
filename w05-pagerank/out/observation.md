# Task 1
수정 전 dead-end 예제는 100회 뒤 총 rank가 0이 됐고, spider trap의 C+D는 1이 됐다. 수정 후 총 rank는 1이고 trap 밖 A=0.0375, B=0.069375가 유지됐다.
Dead end의 점수는 전체 노드에 균등 재분배했다. beta=0.85는 링크를 따라갈 확률이며, 나머지 0.15에는 전체 노드 중 하나로 균등 teleport한다.
재분배가 질량 손실을 막고 teleportation이 닫힌 trap에서 빠져나갈 경로를 제공하므로 두 문제를 함께 해결한다.

# Task 2
beta=0.5→0.99에서 1,200노드 반복은 14→24회였다. beta=0.85의 tolerance=1e-3/1e-6/1e-10은 7/12/20회로, 더 엄격한 종료 기준이 더 많은 반복을 요구했다.
노드를 1,200→20,000으로 늘리자 beta=0.85에서 반복은 20→21회였지만 시간은 0.009495→0.187123s로 약 19.71배 증가했다. 간선 순회 비용과 수렴 횟수는 서로 다르다.
Top-10 구성은 유지됐지만 처음 측정된 변화는 beta=0.7에서 7·8위의 교환이었다. 링크의 비중이 커져 변화가 오래 남고, beta 선택에 따라 순위 해석도 달라질 수 있다.

# Task 3
행렬 대신 실제 링크의 정수 인덱스와 역 out-degree를 저장한다. 그래프 저장은 O(n+m), rank 벡터 두 개와 역수는 3n float 슬롯이며 스칼라 여유 16개까지 포함해 3,616개로 보고했다(dense: 1,440,000개).
Teleportation과 dead-end 재분배는 노드마다 같은 상수를 더하거나 초기화하는 O(n) 연산이다. 모든 노드 쌍을 저장하거나 계산하는 O(n²) 행렬 연산은 필요하지 않다.
공식 bench의 최대 노드 오차는 4.16e-17, 속도는 75.5배, float 수는 398.2배 개선되어 strong 판정을 받았다. 오차는 합산·곱셈 순서와 부동소수점 반올림 차이이며, float 수 비율은 전체 프로세스 메모리 비율이 아니다.
